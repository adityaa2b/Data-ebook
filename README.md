📥 Installation & Usage
Option 1: View Online

Simply visit the live [Demo link](https://adityaa2b.github.io/Data-ebook/HTML/Data.html)

Option 2: Run Locally

1. Clone this repository:

   bash

       git clone https://github.com/adityaa2b/Data-ebook.git

3. Navigate to the directory:

   bash

       cd Data-ebook/HTML

5. Open index.html in your browser:

   bash

       # On macOS
       open Data.html

       # On Linux
       xdg-open Data.html

       # On Windows
       start Data.html

Option 3: Download
- Download the Data.html file and open it directly in any modern web browser.
